# Письма пользователю

Все письма служебные (транзакционные), рассылок нет. Отправка — через SMTP (`SMTP_*`, см. `.env.example`).
Без SMTP письма не отправляются, восстановление пароля по почте отвечает «временно недоступно».
Ответ на любое письмо уходит на support@clymly.ru. Тексты — `src/lib/emails.ts` и `src/lib/email-verify.ts`.

| Письмо | Тема | Когда |
|---|---|---|
| Подтверждение e-mail | Подтвердите e-mail в Clymly | после регистрации и по кнопке «Отправить письмо ещё раз» (ссылка 24 ч) |
| Приветствие | Добро пожаловать в Clymly | один раз, после подтверждения адреса |
| Восстановление пароля | Восстановление пароля в Clymly | по запросу на /forgot-password (ссылка 60 мин, одноразовая; новый запрос отменяет старую) |
| Код для смены пароля | Код для смены пароля в Clymly | в настройках, перед сменой или заданием пароля (6 цифр, 15 мин) |
| Пароль изменён | Пароль в Clymly изменён | после смены пароля по ссылке или в настройках (не при первом задании пароля аккаунтом из JobToo) |
| Код для удаления аккаунта | Код для удаления аккаунта Clymly | в настройках, перед удалением аккаунта (6 цифр, 15 мин) |
| Аккаунт удалён | Аккаунт Clymly удалён | после удаления аккаунта (что стёрто, автопродление отключено, платежи хранятся обезличенно) |
| Pro подключён | Оплата «Pro — 1 месяц» прошла — Clymly | один раз, когда провайдер подтвердил оплату (сумма, период, способ, номер заказа; дата и сумма следующего списания или «Автопродление не включено») |
| Pro продлён | Pro продлён — Clymly | успешное автосписание |
| Скоро продлим Pro | Скоро продлим Pro: <дата> — Clymly | за 3+ дня до автосписания: дата, сумма, карта, как отказаться (10:00–20:00 МСК) |
| Не удалось продлить Pro | Не удалось продлить Pro — Clymly | неудача с основной карты: повтор через 8 часов или другая карта |
| Автопродление Pro отключено | Автопродление Pro отключено — Clymly | не прошло ни с одной карты |
| Карта привязана / удалена / отвязана | … — Clymly | привязка карты, удаление не последней, удаление последней (автопродление выключено) |
| Pro скоро закончится | Clymly Pro закончится <дата> | за 3 дня до окончания, только без автопродления, днём по Москве |
| Период Pro закончился | Период Clymly Pro закончился | после окончания (если закончился не более 7 дней назад), один раз на дату окончания |

Напоминания проверяются раз в час фоновой задачей сервера (`src/instrumentation-node.ts`). Если Pro продлили, дата
окончания меняется — для нового срока письма придут заново.

Восстановление пароля: ответ одинаков для любого адреса (не раскрывает наличие аккаунта), не больше 3 запросов в час
на адрес, после смены пароля завершаются все сеансы, адрес считается подтверждённым. Открытие страницы по ссылке
ссылку не тратит (почтовые сканеры) — она используется при сохранении пароля.

Коды из письма (`src/lib/email-code.ts`): в БД только хеш, новый код отменяет прежний, не чаще раза в минуту и не больше
5 в час, 5 неверных вводов — код сгорает. Смена пароля в настройках завершает сеансы на других устройствах. Без SMTP смена
пароля и удаление аккаунта подтверждаются текущим паролем.

Удаление аккаунта (`src/lib/account-delete.ts`): стираются профиль, резюме, вакансии, адаптации, письма, тренировки,
карты, сеансы и данные JobToo; запись пользователя остаётся обезличенной («Удалённый пользователь»), чтобы платежи
сохранились для учёта и выручки. Адрес освобождается — с ним можно зарегистрироваться снова.

Тест: `node scripts/mail-e2e.mjs` (SMTP-заглушка, см. заголовок файла).
