# Справочник профессий

* Данные: `prisma/data/professions.ts` (исходные 5 групп и 38 профессий) и `prisma/data/professions-more.ts`
  (новые профессии в исходных группах, 20 новых групп по специализациям рынка труда, синонимы). Загружаются в БД при `seed`.
* У каждой профессии: описание, навыки, типичные требования, фокус четырёх уровней (Junior / Middle / Senior / Lead)
  и синонимы (`aliases`) — названия из вакансий, по которым профессию находит поиск и сопоставление должностей из JobToo.
  Однословные синонимы при сопоставлении засчитываются только точным совпадением.
* «Моей профессии нет в списке» — служебная профессия `custom`: название пишет пользователь (`User.professionTitle`).
  ИИ оценивает резюме по общепринятым требованиям к этой профессии и по тексту вакансий; в списке выбора она не показывается.
* Банк вопросов собеседования — только для части профессий; под вакансию вопросы генерирует ИИ (тариф Pro).

Тесты: `npm test` (данные справочника), `npm run e2e` (API, синонимы, своя профессия), `npm run catalog:ui` (выбор в браузере).
