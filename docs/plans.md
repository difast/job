# Тарифы и лимиты

| | Free | Pro |
|---|---|---|
| Анализ резюме (загрузка, пересчёт, смена профессии) | 2 в календарный месяц | без ограничений |
| Разбор вакансии и сравнение с резюме | 1 в календарный месяц | без ограничений |
| Адаптация резюме, PDF | — | да |
| Сопроводительные письма | — | да |
| Тренажёр собеседований (банк вопросов, вопросы под вакансию, оценка ответов) | — | да |

* Логика — `src/lib/billing/entitlements.ts` (`FREE_LIMITS`, `requirePro`, `reserveQuota`). Месяц — календарный, по Москве.
* Использование записывается в `FeatureUse` до обращения к ИИ и удаляется, если операция не удалась: ошибка ИИ лимит не тратит.
  Повторная отправка того же файла или той же вакансии лимит не тратит.
* Смена профессии на Free: если лимит исчерпан, профессия сохраняется, а оценка резюме не пересчитывается.
* Данные из JobToo применяются всегда (переход не обрывается), но засчитываются в лимит (`source = jobtoo`).
* API сверх лимита и Pro-функции на Free отвечают **402** с `upgrade: true` — интерфейс показывает кнопку «Подключить Pro».
* Интерфейс Free: баннер Pro на главной, в «Резюме» и «Вакансиях», остаток лимита, замки в меню у «Письма» и «Собеседования»,
  вместо Pro-разделов — предложение подключить Pro (созданные раньше материалы сохраняются и снова открываются с Pro).
* `FULL_ACCESS_EMAILS` — адреса через запятую с полным доступом ко всем функциям без оплаты (владелец, тестировщики).
  Проверяется e-mail из сессии; в «Тарифе и оплате» и настройках — «Полный доступ». Убрать адрес из списка — доступ снимается.
* `PLAN_LIMITS=off` — отключить лимиты (отладка, старые тесты). В рабочем окружении не задавать.

## Расход ИИ

Каждый запрос к провайдеру записывается в `AiCall`: функция, модель, токены запроса и ответа (из `usage` ответа провайдера),
ошибка, длительность, пользователь. Тексты не хранятся. При удалении аккаунта `userId` обнуляется.
Админка → «ИИ»: токены и запросы за период, по дням, по функциям и моделям, ошибки, пользователи с наибольшим расходом.
Оценка в рублях — если задан `AI_PRICE_PER_1K_TOKENS`.

Тест: `npm run plan:e2e` (мок GigaChat, заглушка оплаты; см. заголовок `scripts/plan-e2e.mjs`). Остальные E2E запускаются с `PLAN_LIMITS=off`.
